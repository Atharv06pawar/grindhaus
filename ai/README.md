# AI Domain (`/ai`)

This folder owns AI runtime concerns and model/engine evolution for GrindHaus.

## Current
- `engine_cpp/`: local C++ coaching engine used by the Node API bridge.

## Future layout
- `engine_cpp/`: deterministic local inference + memory rules.

- `pipelines/`: orchestration for hybrid AI workflows.
- `evaluations/`: quality checks and benchmark suites.
